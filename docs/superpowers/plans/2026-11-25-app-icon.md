# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default Windows icon with the selected green vector-derived mark in the EXE, taskbar, and all application title bars.

**Architecture:** A small Pillow development script produces one clean SVG and a multi-resolution ICO from the same geometry. The .NET build embeds the ICO as the executable icon and as a WPF resource; each Window references that resource. No icon-generation dependency is needed to run or build the app.

**Tech Stack:** SVG, Python 3 + Pillow for asset generation, ICO, .NET 10 WPF/XAML, existing offscreen WPF smoke.

## Global constraints

- Keep the 256-unit concept and palette in the design spec; include 16, 24, 32, 48, 64, 128, and 256-pixel ICO frames.
- Commit generated SVG and ICO so `dotnet build` and `dotnet publish` need no Python.
- Apply one icon to the EXE and all six application windows; do not change package or environment behavior.
- Verify with fake-data UI checks, a real `win-x64` publish, and visual inspection at small sizes.
